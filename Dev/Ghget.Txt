================================================================================
  MERGE WORKFLOW (RECOMMENDED)
================================================================================

1. Create a merge workspace:
   mkdir -p /merge/source && cd /merge/source

2. Download all DekkCore content you want:
   ghget devovh/Shadowlands_Dekk-Core src/server/scripts/DekkCore/BattleforAzeroth/CrucibleOfStorms ./CrucibleOfStorms
   ghget devovh/Shadowlands_Dekk-Core src/server/scripts/DekkCore/Draenor/Ashran ./Ashran
   (etc.)

3. Adapt to Titans structure:
   - Copy CrucibleOfStorms -> Titans/src/server/scripts/CrucibleOfStorms
   - Copy Ashran -> Titans/src/server/scripts/Draenor/Ashran
   - Update Titans/src/server/scripts/CMakeLists.txt to register new script dirs
   - Update script names in DB if they differ from Titans naming convention

4. Download SQL fixes:
   ghget freadblangks/AzgathCore-1 sql/updates/world ./sql-world
   # Apply all .sql files in order to your world database

5. Compile and test:
   cd Titans && mkdir build && cd build && cmake .. && make -j$(nproc)

================================================================================
  IMPORTANT NOTES
================================================================================

- DekkCore uses a different subfolder structure (`src/server/scripts/DekkCore/`)
  You MUST adapt the CMakeLists.txt and script registration when merging into
  Titans (which uses `src/server/scripts/` directly).

- Script names in DekkCore may use different CreatureScript/SpellScript names.
  Search and replace may be needed to match Titans' naming conventions.

- The Dekk-Shadowlands repository is a Shadowlands (9.0+) emulator. Its BFA
  scripts are compatible with Titans' API because both are TrinityCore-derived.
  However, some spell IDs or creature entries may differ if DekkCore uses
  Shadowlands-era DB values. Always test after merge.

- Binary files (.rar, .7z, .zip) cannot be downloaded via ghget. Use curl/wget
  for the boom8866 database archives.
