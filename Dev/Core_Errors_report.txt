 FIX #1 - InspectHandler.cpp: Old field API used for honor kill stats
===========================================================================
FILE: src/server/game/Handlers/InspectHandler.cpp
FUNCTION: WorldSession::HandleRequestHonorStatsOpcode
LINES: 96-98

WHAT WAS WRONG:
  The handler used the old TrinityCore direct-field-read API to fetch
  honor kill stats for the inspect target:
    honorStats.LifetimeHK  = player->GetUInt32Value(ACTIVE_PLAYER_FIELD_LIFETIME_HONORABLE_KILLS);
    honorStats.YesterdayHK = player->GetUInt16Value(ACTIVE_PLAYER_FIELD_KILLS, ...);
    honorStats.TodayHK     = player->GetUInt16Value(ACTIVE_PLAYER_FIELD_KILLS, ...);

  Neither GetUInt32Value nor GetUInt16Value exist anywhere in this
  core's Object.h or any game header. ACTIVE_PLAYER_FIELD_LIFETIME_HONORABLE_KILLS
  and ACTIVE_PLAYER_FIELD_KILLS don't exist either. This is a compile
  error that would prevent the worldserver from building.

  Note: Line 73 in the same file (HandleInspectOpcode) ALREADY uses the
  correct BFA method for the same data:
    inspectResult.LifetimeHK = player->m_activePlayerData->LifetimeHonorableKills;

FIX APPLIED:
  Lines 96-98 updated to use the same typed update-field accessor:
    honorStats.LifetimeHK  = player->m_activePlayerData->LifetimeHonorableKills;
    honorStats.YesterdayHK = player->m_activePlayerData->YesterdayHonorableKills;
    honorStats.TodayHK     = player->m_activePlayerData->TodayHonorableKills;

  UF::ActivePlayerData fields confirmed present in UpdateFields.h:
    UpdateField<uint32, 66, 77> LifetimeHonorableKills;
    UpdateField<uint16, 66, 76> YesterdayHonorableKills;
    UpdateField<uint16, 66, 75> TodayHonorableKills;

SEVERITY: Compile error. Would prevent worldserver from building.
